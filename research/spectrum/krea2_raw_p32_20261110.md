# Krea 2 Raw — 52-step P32 SPECTRUM research profile

Status: **owner-approved for research use**, opt-in only (2026-11-10). This is **not** a general model qualification, Product/Stable adoption, or a change to the default pipeline. In particular, P34 and above were judged challenge-only because semantic detail begins to break even when composition remains plausible.

- Previous experiment: `KREA2_0421_P32_BOUNDARY_V04_RETURN.zip` / `KREA2_RAW_0421_P32_BOUNDARY_COLAB_V04_20261110.ipynb` (the same five-file STAGED adapter, now promoted). This is one experiment and its return, **not** independent evidence sources.

## Explicit opt-in

```python
from diffusers.hooks.spectrum_cache import SpectrumCacheConfig

KREA2_RAW_P32_52 = (
     7,  8,  9, 10, 11, 13, 15, 16, 17, 19, 21, 23, 24, 25, 27, 28,
    29, 30, 31, 32, 33, 35, 37, 39, 40, 41, 42, 43, 44, 45, 47, 49,
)

config = SpectrumCacheConfig(
    num_inference_steps=52,
    denoiser_call_topology="paired_cfg",
    forecast_step_indices=KREA2_RAW_P32_52,
    predictor_backend="dense",
    coordinate_policy="runtime_horizon_normalized",
    coordinate_max=100.0,
    degree=4,
    ridge_lambda=0.1,
    blend_w=0.5,
    history_limit=8,
    warmup_steps=0,
    window_size=2.0,
    flex_window=0.0,
    tail_actual_steps=0,
)

pipe.transformer.enable_cache(config)
try:
    # `pipe` and `prompt` must already be set. For the original evidence,
    # reuse the V04 frozen prompt, conditioning and seed.
    output = pipe(prompt=prompt, height=1024, width=1024, num_inference_steps=52, guidance_scale=3.5)
finally:
    pipe.transformer.disable_cache()
```

The route requires a 28-block standard Krea 2 Raw architecture, native `cache_context("krea")`, explicit P32 schedule, sequential paired CFG, and the horizon-normalized policy. Incompatible configuration fails before hooking, and dynamic/incorrect contexts latch to full computation. No other model family or default path is changed. Do not silently extend this profile to different steps, CFG, weights, resolutions, or prompts.

## Boundaries

- Source integration adds an adapter, model cache support, pipeline context wiring, and a small CPU synthetic regression. It does not enable cache by default.
- L4 visual review is already complete for P32; this commit does **not** rerun a GPU test. New or changed weights/shape/topology require a fresh bounded check.
- Product, Stable, ZeroGPU and L2 are unchanged. The present branch remains research-only.
